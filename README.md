# 叫家琦来：桌面文件清理小剧场

这是从 `MonsterDeleter` 改造而来的 Windows 桌面互动工具。右键选择一个文件或文件夹后，Q 版家琦会从屏幕边缘走到目标旁边，确认一下，然后一脚把它踢进回收站；命中瞬间，目标的系统图标还会按抛物线旋转飞出屏幕。

## 当前角色

最终角色采用统一生成并离线加工好的 Q 版逐帧精灵：

- 短黑发、黑色矩形眼镜；
- 灰色日常 Polo 衫、深色长裤、浅灰运动鞋；
- 冷静、斯文、略带一点拽感的“冷面执行官”气质；
- 三套标准等宽动作资源：走路、踢击、扶眼镜收尾。

运行时不再抠图或重新排版精灵，只负责等宽切帧和播放。素材整理属于离线美术流程，避免为了临时素材问题把播放器复杂化。

## 动画导演

走路按现有关键帧重新剪辑：

```text
起步：1 → 2 → 3
巡航：3 → 6 → 4 → 2 → 循环
停车请求：等待第 3 帧结束
收步：6 → 7 → 8 → 9
等待确认：第 9 帧正面站立 + 1px 轻呼吸
用户确认：9 → 8 → 7 快速转回目标
```

当前节奏：

- 行走速度约 `390 px/s`；
- 巡航时长 `105 / 85 / 105 / 85ms`，并对第 4 / 2 帧应用最多 1px 的视觉稳定补偿；
- 收步 `120 / 140 / 160 / 220ms`，同时使用缓出位移停到目标；
- 踢击使用变速时长，只有第 5 帧是命中帧；
- 胜利动画约 1.5 秒，其中微笑帧停留 `420ms`。

## 踢飞图标

命中时不会去移动 Explorer 里的真实桌面图标，而是先捕获目标文件或文件夹的系统图标，再执行回收站操作。删除成功后，透明覆盖层生成一个图标替身：

- 初始水平速度约 `1050 px/s`；
- 初始向上速度约 `680 px/s`；
- 向下重力加速度约 `1650 px/s²`；
- 同时以约 `720°/s` 自旋；
- 飞出屏幕后自动销毁。

这样视觉上像目标真的被一脚踹飞，但底层删除逻辑仍然只负责把右键菜单传入的路径移入回收站。`--demo` 模式使用通用文件图标演示同样的抛体效果，不会真正删除内容。

## 使用

### 源码运行

```powershell
pip install -r requirements.txt
python main.py --demo
```

演示模式只播放动画，不会删除内容。

正常运行：

```powershell
python main.py
```

程序会注册 Windows 右键菜单“叫家琦来收拾它”，随后启动安全演示。之后右键任意文件或文件夹即可使用。

也可以明确注册或移除菜单：

```powershell
python main.py --install-menu
python main.py --uninstall-menu
```

### 测试

```powershell
pip install -r requirements-dev.txt
python -m pytest -q
```

### 打包

```powershell
.\build.ps1
```

生成文件位于 `dist\叫家琦来.exe`。

## 交互流程

1. 右键选择文件或文件夹；
2. 点击它在屏幕上的位置；
3. 家琦从屏幕边缘走入，并自动朝向目标；
4. 接近目标时等待正确腿相位，再减速收步并转成正面；
5. 家琦正面看着用户等待确认；
6. 点击“嘤嘤嘤，就是这个！”后，先快速转回目标再踢击；
7. 踢击第 5 帧命中时，目标被移入回收站、爆炸，同时系统图标替身旋转飞出屏幕；
8. 踢完后慢速播放扶眼镜、微笑、恢复冷脸的收尾动作；
9. 点击“不是不是”可重新选择舞台位置，`Esc` 可随时退出。

点击位置只用于安排动画舞台，真正处理的目标始终是右键菜单传入的路径，避免误删旁边的图标。

## 项目结构

```text
app/
  character.py       角色参数与锚点配置
  chibi_avatar.py    等宽精灵播放器与动作状态机
  context_menu.py    文件和文件夹右键菜单
  delete_service.py  回收站操作
  explosion.py       爆炸效果
  flying_icon.py     系统图标捕获与抛体飞行效果
  overlay.py         全屏交互、人物位移与动作流程
characters/jiaqi/
  character.json     人物尺寸、速度、命中锚点和台词
  sprites/
    walk.png          9 帧标准走路素材
    kick.png          8 帧标准踢击素材
    victory.png       6 帧标准扶眼镜收尾素材
main.py               程序入口
build.ps1             Windows 打包脚本
```
